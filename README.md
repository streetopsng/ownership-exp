# Ownership Deep Dive: Accountability, Agency & Execution

An interactive masterclass experience unpacking why ownership vanishes in growing teams, how psychological agency functions, and how to build RACI structures that drive single-threaded accountability.

## Tech Stack
- **React 19**
- **Vite 8**
- **Tailwind CSS v4**

## Features
- 💎 **5 Core Modules**: Psychological Ownership, Diffusion of Responsibility, RACI Structures, Decision Rights, and Culture Architecture.
- ⌨️ **Keyboard Navigation**: Use Left and Right arrow keys or spacebar to navigate seamlessly.
- 🎨 **Executive UI**: Clean, responsive, typography-focused design built with Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```
